## 📋 Program Index

| File | Topic / Description | Concepts Used |
| :--- | :--- | :--- |
| [`001_hello.html`](./Internal%20js/001_hello.html) | Hello World | Basic JavaScript syntax, `document.write()` |

| [`003_addOf2.html`](./Internal%20js/003_addOf2.html) | Static Addition of Two Numbers | Variable declaration (`let`), addition operator |

## 💡 Key Topics Covered

- **Variables & Declarations:** `let`
- **User Interaction:** `prompt()` for user input
- **Output:** `document.write()` with HTML tags
- **Data Types & Type Conversion:** Strings, Numbers, `Number()` function
- **Operators:** Arithmetic (`+`, `-`, `*`, `/`), Assignment (`=`), Comparison (`==`)
- **Control Flow:** Conditional statements (`if`, `else`, nested `if`)

## 🚀 How to Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/lakshyakurvey19-code/Java-Script.git
   ```
2. **Navigate into the directory:**
   ```bash
   cd "Java-Script/Internal js"
   ```
3. **Open any `.html` file** in your browser, or use the **Live Server** extension in VS Code.
